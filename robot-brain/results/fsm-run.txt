# 1. 阈值附近，状态会翻多少次
###############################################################
== 五个 150 ms 的坑，间隔 200 ms，距离噪声 ±2 cm ==
   1 kHz，6 秒，共 6000 拍

-- A  单阈值 0.45 / 0.45，无驻留
   状态翻转   60 次   进入避障  29 次
   避障时间占比   7.4%   平均速度 0.285 m/s

-- B  双阈值 0.40 / 0.55，无驻留
   状态翻转   12 次   进入避障   5 次
   避障时间占比   8.5%   平均速度 0.283 m/s

-- C  双阈值 0.40 / 0.55，驻留 300 ms
   状态翻转    8 次   进入避障   3 次
   避障时间占比  19.8%   平均速度 0.260 m/s

# 2. 表里没写的边，能不能走过去
###############################################################
== 一段事件序列，两种写法 ==

  时间   距离   事件     表驱动   if 链
  0.00   0.80   RESET    IDLE     IDLE    
        上电复位
  0.10   0.80   START    RUN      RUN     
        上层发开始
  0.50   0.80   ESTOP    FAULT    FAULT   
        急停按下
  0.60   0.80   -        FAULT    RUN     ← 不一致
        急停松开，没人复位
  1.00   0.80   START    FAULT    RUN     ← 不一致
        上层重发开始
  1.50   0.30   NEAR     FAULT    AVOID   ← 不一致
        前方出现障碍
  2.00   0.80   RESET    IDLE     RUN     ← 不一致
        有人按了复位

  表驱动拒绝了 2 个事件（表里没有这条边）
  两种写法有 4 个时刻不一致

  表里一共 15 条边，这一趟走过 4 条
  走过的边：
    BOOT --RESET--> 1 次
    IDLE --START--> 1 次
    RUN --ESTOP--> 1 次
    FAULT --RESET--> 1 次

# 3. 驻留期里按了急停
###############################################################
== t=100 ms 进避障（驻留 300 ms），t=101 ms 按下急停 ==

   安全事件绕过驻留   第 101 ms 进 FAULT，比按下晚 0 ms
   安全事件不绕过     第 400 ms 进 FAULT，比按下晚 299 ms

   多等的 299 ms 里，车以 0.10 m/s 又走了 3.0 cm，以 0.30 m/s 是 9.0 cm
