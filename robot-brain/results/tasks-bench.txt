每拍 tick 一次要多久，三轮测量的第一轮（三轮差别在 1 ns 以内）
./bin/bench-tick

== 走完一遍顺序要多久（含一次 task_reset）==

  挂 1 个                    7.8 ns
  挂 2 个                   14.2 ns
  挂 4 个                   26.6 ns
  挂 8 个                   45.3 ns
  ── 每多挂一个任务          5.4 ns

== 整棵树 ==

  一个真实叶子（前进）      15.0 ns
  整棵树（抢占+顺序4+避障）  22.8 ns
  占 20 ms 周期            0.0001%

三轮原始值：
  挂 1 个      8.1 / 8.1 / 8.5 / 7.8 ns
  挂 8 个     45.5 / 47.5 / 47.3 / 45.3 ns
  每多挂一个   5.3 / 5.6 / 5.5 / 5.4 ns
  真实叶子    15.6 / 15.9 / 15.5 / 15.0 ns
  整棵树      23.1 / 43.0 / 22.5 / 22.8 ns   （43.0 是宿主机抖动，取中位数 23）
